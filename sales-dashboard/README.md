# SKU 손익 사령탑 (Sales & Ads Dashboard)

코코도르 전사 매출·광고·생산·재고·구매 통합 대시보드.

**게시 주소** — https://claude.ai/artifact/FweXy6vGtQ3THt4e4tYUy7

> 이 폴더는 **게시된 아티팩트의 스냅샷 백업**입니다.
> 원본 분석 파이프라인은 작업 세션 컨테이너에만 있었고 세션 보관 시 회수되어 남아 있지 않습니다.
> 따라서 현재로서는 `index.html` + `data.js` 자체가 유일한 원본입니다.

## 구성

```
index.html   대시보드 화면 — 16개 대분류, 150개 이상 뷰
data.js      분석 결과 데이터 (window.APP_DATA), 약 16.7MB
```

## 메뉴 대분류

0 데이터 등록 · 1 전체 매출 현황 · 2 전사 영업 현황(쿠팡/아마존/네이버) ·
3 상품 · 4 재고 · 5 광고 · 6 히어로 상품 · 7 고객 평점 · 8 경쟁사 현황 ·
9 SKU 건강도 진단 · 10 브랜드파워 · 11 신제품개발 · 12 생산관리(API/실측) ·
13 재고관리(API/실측) · 14 구매관리 · 15 교육 · 16 공지사항

## 수정 방법

파이프라인이 없으므로 다음 방식으로 수정합니다.

1. **화면 수정** — `index.html` 의 해당 `renderVxx()` 함수를 직접 편집
2. **데이터 추가** — `data.js` 의 `window.APP_DATA` 에 키를 추가하고, 그 키를 읽는 뷰 함수를 작성
3. **재게시** — `index.html` 을 `files: {"data.js": ...}` 와 함께 같은 URL 로 publish

## 주의

- **인건비는 이 대시보드에 연결하지 않습니다.** 인사 데이터는 민감 정보로 `hr-dashboard/` 에 분리되어 있습니다.
- 공유 링크가 과거 버전에 고정되어 있으면 팀원은 옛 화면을 봅니다. 아티팩트 공유 메뉴에서 공유 버전을 최신으로 갱신하십시오.
