## 구성 파일

```
hr-dashboard/
  index.html   대시보드 화면 (뷰 라우팅·검증 리포트·개인별 급여명세 조회)
  data.js      분석 결과 데이터 (window.HR_DATA)
analysis/
  analyze.py   원본 급여 엑셀 → data.js 생성 파이프라인
```

## 분석 파이프라인

`analysis/analyze.py` 는 아래 원본에서 `data.js` 를 생성합니다.

- `00.코코도르 외 급여_2026.02.xlsx` — 2026-02 급여대장 154명(지급 16항목·공제 14항목), 직원명부, 연장·출장 집계
- `2508 급여.xlsx` — 2025-07 계약급여, 2025-06 집계 시트
- `2506 인건비통합 3년간 비용.xlsx` — 2023-01~2025-05 월별 인건비·매출
- SKU 손익 사령탑 대시보드 — ERP 전사 매출 (2025년 12개월, 2026년 1~8월)

```bash
pip install openpyxl
python3 analysis/analyze.py      # 원본 xlsx 가 같은 디렉터리에 있어야 합니다
```

## 검증 규칙 (17개)

R1~R3 합계 산식(지급·공제·실지급), R4~R6 4대보험 요율·상한, R7 4대보험 가입,
R8 최저임금, R9 기본급 누락, R10~R11 소득세·지방소득세, R12~R14 조직·입사일 마스터,
R15 명부-대장 대조, R16 집계표 대사, R17 연장수당 시트 대사.

휴직·중도입퇴사자는 일할계산으로 급여가 줄어들기 때문에 최저임금 검증에서 제외하고,
외국인 장기요양 가입제외 추정 건은 오류가 아닌 `참고` 로 분류합니다.

## 알려진 한계

- 2024~2025년 `전사 급여내역` 파일 3종이 **암호로 보호**되어 열람 불가 → 개인별 히스토리가 2개 시점으로 제한됨
- 2025년 7·8·9월, 2026년 3월 이후 인건비 원본 미확보
- 매출 기준 혼재: 2023~2024년은 4개 법인 합산, 2025~2026년은 ERP 전사 매출
- 외국인 여부는 성명 표기 기반 추정 (국적 데이터 아님)
- 대만 법인은 집계에서 제외 (국내 2개 법인만)
