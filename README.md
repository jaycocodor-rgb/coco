## 개인정보 취급

`hr-dashboard/data.js` 에는 직원 169명의 성명·사번·부서·급여 전 항목이 들어 있어
**저장소에 커밋하지 않습니다**. 개인 인명이 하드코딩된 추출 스크립트(`analysis/taiwan.py`,
`analysis/extract_contract_master.py` 등)도 같은 이유로 제외 대상입니다.

암호를 해제한 「전사 급여내역」 원본에는 **주민등록번호·휴대폰번호·주소**가 포함되어 있으나,
추출 단계에서 해당 3개 컬럼을 차단하고 결과물에 해당 패턴이 남지 않았는지 자동 검사합니다.

```python
assert not re.search(r'\d{6}-\d{7}', blob), 'PII 주민번호'
assert not re.search(r'01[016-9]-?\d{3,4}-?\d{4}', blob), 'PII 휴대폰'
```

게시된 대시보드에는 **직원 실명과 개인별 급여액**이 담겨 있습니다.
링크를 받은 사람은 전부 열람할 수 있으므로 인사파트 외 공유를 제한하십시오.
